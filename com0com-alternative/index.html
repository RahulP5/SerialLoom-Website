A com0com alternative for Windows 10 and 11

SerialLoom gives you virtual null-modem pairs like com0com, plus splitting, joining and TCP bridging, without test-signing mode and with a visual editor.

Download for Windows Read the guide

Why people look for a com0com alternative

com0com is a long-standing open-source null-modem emulator for Windows, and together with its companion tools hub4com and com2tcp it has served developers for years. On current PCs, though, users often run into the same issues:

  • Driver signing: com0com is a kernel driver. Its recent 64-bit builds are not signed by Microsoft for production use, so 64-bit Windows 10 and 11 refuse to load them unless you enable test-signing mode, which in turn requires turning off Secure Boot.
  • Configuration: port pairs are set up with a basic setup utility or the command line, and splitting a port or sharing it over TCP means learning hub4com or com2tcp command-line options.
  • Visibility: there is no built-in way to watch the data passing through.

Commercial virtual serial port drivers avoid the signing problem, but cost a license per PC.

How SerialLoom avoids test mode

Instead of shipping its own unsigned kernel driver, SerialLoom presents each virtual port as a software USB serial device. Windows serves it with its own built-in usbser.sys driver, through a bundled virtual USB controller whose drivers Microsoft has signed. More on how it works.

Moving from com0com

  1. Note the COM numbers your com0com pairs use, for example COM10 ⇄ COM11.
  2. Remove the com0com pairs (or uninstall com0com) so those numbers are free, then turn test-signing mode off if you only enabled it for com0com.
  3. Install SerialLoom, press Virtual pair, and give the new ports the same numbers.
  4. Replace hub4com and com2tcp scripts with a split or a TCP bridge on the canvas.

Where SerialLoom is still growing

SerialLoom is young, and we would rather you know its limits up front:

  • Virtual ports exist while SerialLoom runs (it keeps running in the notification area when you close the window). Running the engine as a Windows service is planned.
  • Baud rate and DTR/RTS are not yet passed end to end between ports, and RFC 2217 for TCP is planned.
  • Windows x64 only for now; a command-line interface and Linux support are on the roadmap.
  • The installer is not code-signed yet, so SmartScreen asks you to confirm the first run.

Ideas and bug reports are welcome on GitHub Issues.

Questions

Can SerialLoom and com0com be installed together?

They use different mechanisms, so they can coexist. Just avoid giving ports from both the same COM number.

Is SerialLoom a replacement for Virtual Serial Port Driver or similar paid tools?

For creating virtual ports, pairs, splitting and TCP bridging on a Windows PC, yes, and it is free. Check the limits listed above against your needs.
