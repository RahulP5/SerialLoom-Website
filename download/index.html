Download SerialLoom

Free, open-source virtual COM port software for Windows 10 and 11. One installer sets up everything virtual ports need.

Download installer (x64) All releases
  • Latest v0.1.1
  • Windows 10 (1803+) & 11, x64
  • MIT license

Requirements

Windows 10 version 1803 or later, or Windows 11, on a 64-bit (x64) PC. The installer downloads Microsoft Edge WebView2 if it is missing (it is built into Windows 11).

What gets installed

The SerialLoom app and a virtual USB controller (usbip-win2) whose drivers are signed by Microsoft. If usbip-win2 is already installed, SerialLoom reuses it. No test mode needed.

Clean uninstall

Uninstall from Settings > Apps. It removes SerialLoom's virtual ports, and the USB controller if SerialLoom installed it.

Install in three steps

  1. Run the installer

    Open SerialLoom_x.y.z_x64-setup.exe from your downloads.

  2. Confirm SmartScreen

    The installer is not code-signed yet, so Windows may say “Windows protected your PC”. Choose More info > Run anyway.

  3. Allow administrator access

    Installing the virtual USB controller, and creating, renumbering or removing ports later, need administrator permission.

Open and verifiable

Every release is built from the public source code by GitHub Actions, and the tests run before each build. You can read every line, or build the installer yourself:

git clone https://github.com/RahulP5/SerialLoom.git
cd SerialLoom
npm install
.\scripts\fetch-usbip-win2.ps1
npm run app:build

See the build instructions for prerequisites. Found a problem? Open an issue, or report security issues privately as described in the security policy.
